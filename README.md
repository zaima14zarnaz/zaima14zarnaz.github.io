## Repository name

Create the repository with this exact name:

`zaima14zarnaz.github.io`

## Deploy

1. Log in to GitHub as `zaima14zarnaz`.
2. Create a **public** repository named `zaima14zarnaz.github.io`.
3. Upload everything in this folder to the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Save.

The website should then appear at:

https://zaima14zarnaz.github.io/
